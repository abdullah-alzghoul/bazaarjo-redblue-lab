# VM2 SIEM Configuration

## Purpose

This directory contains the Security Information and Event Management (SIEM) configuration used by VM2 in the Bazaarjo Red/Blue Lab environment.

VM2 is responsible for receiving, indexing, and analyzing security events generated by VM1.

## Responsibilities

VM2 performs:

- Syslog collection from VM1.
- Apache access log monitoring.
- Security event indexing.
- Detection query execution using Splunk Enterprise.

## Log Sources

VM2 receives:

1. Apache access logs from VM1.
2. Bash audit logs from VM1.
3. System security events.

## Configuration Files

### config/splunk_inputs.conf

This file defines Splunk data inputs including:

- UDP Syslog receiver on port 514.
- Apache access log monitoring.
- Splunk internal logging.

## Network Communication

VM1 → VM2

Protocol:

UDP 514 (Syslog)

Source:

VM1 Target Application

Destination:

VM2 SIEM

## Detection Integration

Detection rules are stored separately in:

detection-queries/

These rules analyze collected logs to identify:

- SQL Injection attempts.
- Command Injection attempts.
- XSS attacks.
- Web shell activity.
