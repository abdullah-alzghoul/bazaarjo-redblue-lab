# Security Notice

## Purpose

This repository was created for educational cybersecurity training purposes only.

The vulnerable application included in this project intentionally contains security weaknesses to demonstrate:

- Penetration testing techniques.
- Detection engineering.
- Incident response.
- Secure code remediation.

## Important Warning

The vulnerable application must only be deployed inside an isolated laboratory environment.

Do not expose this project to:

- Public networks.
- Production systems.
- Untrusted users.

## Responsible Usage

All testing activities should be performed only on systems where authorization has been granted.

The project demonstrates the complete security lifecycle:

1. Vulnerability creation.
2. Exploitation.
3. Detection.
4. Remediation.
5. Verification.
